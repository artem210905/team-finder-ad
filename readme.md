# TeamFinder

**TeamFinder** — это платформа для поиска команд и совместной работы над проектами. Платформа позволяет пользователям находить интересные идеи, собирать единомышленников и управлять статусом своих разработок.

В данном проекте полностью реализован **Вариант №1**: добавлена система «Избранного» для проектов

## Стек технологий
* **Backend:** Python 3, Django
* **База данных:** PostgreSQL
* **Контейнеризация БД:** Docker, Docker Compose
* **Frontend:** HTML, CSS, JavaScript (интеграция готовых шаблонов)

## Запуск проекта локально

### 1. Клонирование репозитория и виртуальное окружение
Склонируйте проект на свой компьютер и перейдите в папку проекта:

    git clone https://github.com/artem210905/team-finder-ad.git
    cd team-finder-ad

Создайте и активируйте виртуальное окружение:

Для Windows:

    python -m venv venv
    venv\Scripts\activate

Для Mac/Linux:

    python3 -m venv venv
    source venv/bin/activate

Установите зависимости:

    pip install -r requirements.txt

### 2. Настройка переменных окружения (.env)
Создайте файл `.env` в корне проекта (рядом с `manage.py`). Вы можете скопировать пример из файла `.env_example`:

    cp .env_example .env

Заполните файл `.env` вашими данными:
| Переменная | Описание |
| --- | --- |
| `DJANGO_SECRET_KEY` | Секретный ключ Django (обязательно для продакшена). |
| `DJANGO_DEBUG` | Режим отладки (`True` для локальной разработки, `False` для продакшена). |
| `ALLOWED_HOSTS` | Список разрешенных хостов через запятую (например: `127.0.0.1,localhost`). |
| `POSTGRES_DB` | Имя базы данных. |
| `POSTGRES_USER` | Имя пользователя БД. |
| `POSTGRES_PASSWORD` | Пароль пользователя БД. |
| `POSTGRES_HOST` | Хост для подключения к БД (локально — `localhost`). |
| `POSTGRES_PORT` | Порт БД (в данном проекте используется 5436). |

### 3. Запуск базы данных
Проект использует PostgreSQL. Для быстрого запуска базы данных поднимите Docker-контейнер:

    docker compose up -d

*(Для остановки базы данных используйте команду `docker compose down`)*

### 4. Миграции и запуск сервера
Примените миграции для создания таблиц в базе данных:

    python manage.py migrate

Создайте суперпользователя (администратора) для доступа к панели управления:

    python manage.py createsuperuser

Запустите локальный сервер:

    python manage.py runserver

Проект будет доступен по адресу: http://127.0.0.1:8000/
